# Third-party software

Open Books depends on, but does not bundle, the following. Check each licence for your use.

| Dependency | Used for | Where | Licence (as declared by the package) |
|---|---|---|---|
| jsonschema | schema validation | core (always) | MIT |
| openpyxl | `.xlsx` workbooks | core `[xlsx]` (installed by every provider) | MIT |
| **PyMuPDF** | PDF text and page rendering | statements `[pdf]` | **AGPL-3.0, or a commercial licence from Artifex** |
| EasyOCR | OCR of scans | statements `[scan]` | Apache-2.0 |
| python-bidi (via EasyOCR) | text direction | statements `[scan]` | LGPL |
| PyTorch, torchvision | OCR and the typed heads | statements `[scan]` | BSD-style |
| NumPy | arrays | statements `[scan]` | BSD-3-Clause |
| Ajv | schema validation in JS | `@openbooks/core` | MIT |
| Commander | CLI | `openbooks` | MIT |

**PyMuPDF.** It is optional and only the `[pdf]` and `[scan]` extras install it. If you distribute software that includes it, or
offer it to users over a network, the AGPL's obligations apply to that software unless you hold a commercial licence from
Artifex. This is not legal advice; ask counsel.

The shipped model weights were trained from scratch on synthetic statements generated by this project. No third-party
dataset and no pretrained checkpoint was used.
