Open Books reads bank statements, payment settlements, tax documents and workpapers. Each run returns either a released `openbooks.v1` document with verifiable checks and source evidence or a typed refusal.

[Open the workspace](/app) to try a sample, upload financial files, and inspect release decisions. [Read the workspace guide](/docs/workspace) for upload, review, and export workflows.

## From a file to a decision

<ol className="ob-flow">
  <li><strong>Detect</strong><span>Match a known document layout.</span></li>
  <li><strong>Extract</strong><span>Read fields and record where they came from.</span></li>
  <li><strong>Verify</strong><span>Reconcile the amounts and check independent evidence.</span></li>
  <li><strong>Return</strong><span>Release the complete JSON or return a refusal.</span></li>
</ol>

## Choose an integration

| Environment | Entry point | Use it for |
| --- | --- | --- |
| Python 3.11+ | [`openbooks`](/docs/python) | Run the engine inside a Python process with control over the extraction options. |
| Node.js 20+ | [`@lumeo_hq/openbooks-core`](/docs/node) | Run the local Python engine from Node.js and consume typed results. |
| Terminal | [Python and npm CLI commands](/docs/cli) | Convert files, run diagnostics and script batch jobs. |
| Self-hosted HTTP | [FastAPI engine service](/docs/engine-api) | Stream batches from a trusted application server. |
| AI agent | [Model Context Protocol](/docs/mcp) | Process local financial files and inspect released records, assertions and evidence. |
| Browser | [Open the workspace](/app) | Try synthetic samples and inspect assertions, rows and source evidence. |

Check [supported formats](/docs/formats) for the layouts, dates, currencies and OCR options each source needs. Agents can read the [documentation index](/llms.txt) or [complete Markdown export](/llms-full.txt).

The public engine packages are at 0.2.0. Training and evaluation use synthetic documents. Test the layouts you need before relying on the results in a production workflow.
